# Generador de Versículos Diarios

Una aplicación web y móvil minimalista desarrollada con React Native y Expo. Muestra versículos bíblicos aleatorios con una estética tipográfica inspirada en Neon Genesis Evangelion y ofrece recursos de ayuda emocional.

## Características

*   **Versículos aleatorios**: Consume la API de bible-api.com para mostrar un texto diferente cada dos minutos.
*   **Diseño inmersivo**: Interfaz oscura con animaciones de opacidad y desplazamiento al cargar nuevos textos.
*   **Recursos de apoyo**: Incluye apartados informativos y líneas telefónicas de prevención y ayuda urgente en España.

## Tecnologías utilizadas

*   React Native
*   Expo
*   TypeScript

## Cómo ejecutar el proyecto

1.  Instala las dependencias necesarias:
    ```bash
    npm install
    ```

2.  Inicia el servidor local:
    ```bash
    npm start
    ```

3.  Para visualizar la aplicación en el navegador web, presiona la tecla `w` en la terminal.
